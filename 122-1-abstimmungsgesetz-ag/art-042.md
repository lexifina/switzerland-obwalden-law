# Art. 42 Mehrfach Vorgeschlagene
1 Steht eine vorgeschlagene Person auf mehr als einem Wahlvorschlag, fordert der Gemeinderat sie auf, bis zum 37. Tag (dem sechstletzten Freitag) vor dem Wahlsonntag zu erklären, auf welchem Vorschlag ihr Name stehen bleiben soll. Erfolgt keine Erklärung, so entscheidet dies der Gemeinderat durch das Los. Auf den andern Wahlvorschlägen ist dieser Name zu streichen.
