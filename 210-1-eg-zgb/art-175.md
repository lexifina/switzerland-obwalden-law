# Art. 175 Verständigungsversuch, Weisungsschein
1 Wenn der Eigentümer eines angeblich belasteten Grundstückes ein von einem Dritten behauptetes Recht bestreitet, so soll die Bereinigungskommission der betreffenden Gemeinde zwischen den Beteiligten eine Verständigung herbeizuführen suchen. Wird eine solche nicht erzielt, so steht dem Ansprecher der Zivilprozessweg offen.
