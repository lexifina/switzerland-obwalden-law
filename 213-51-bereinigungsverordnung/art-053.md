# Art. 53 Richterlicher Entscheid
1 Wird die Notwendigkeit einer Änderung der Grenzen bestritten, so setzt das Bereinigungsamt dem Einsprecher eine Frist von 20 Tagen an, um auf dem Zivilprozessweg Klage auf Festlegung der Grenzen einzureichen.
2 Wird keine Klage eingereicht oder wird die Klage abgewiesen, so werden die vom Geometer ausgefertigten Mutationsakten rechtskräftig.
