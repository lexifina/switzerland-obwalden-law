# Art. 11 Administrativmassnahmen
1 Wer die Vorschriften der Fischereigesetzgebung verletzt, dem kann das Amt für Landwirtschaft und Umwelt das Patent entziehen. In leichten Fällen kann sie eine Verwarnung aussprechen, welche auf dem Patent vermerkt wird. Für den Patententzug wird eine Entscheidgebühr von Fr. 50.– erhoben.
